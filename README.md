# 📚 Sistema de Gestão Bibliotecária - Biblioteca Anísio Teixeira

Este projeto é um Sistema de Organização de Biblioteca Escolar, desenvolvido em Java com interface gráfica em Swing, utilizando SQLite como banco de dados.
O objetivo é facilitar o gerenciamento do acervo de livros e o controle de empréstimos e devoluções dos alunos.

## 🚀 Funcionalidades

Cadastrar Livro
Registre novos livros informando título, autor, gênero e ISBN.

Visualizar Acervo
Consulte todos os livros cadastrados, com informações de disponibilidade.

Registrar Empréstimo
Associe livros a alunos, incluindo turma, data de empréstimo e devolução.

Visualizar Empréstimos Ativos
Veja a lista de empréstimos em andamento, com opção de registrar devolução.

Controle de Disponibilidade
O sistema atualiza automaticamente a disponibilidade do livro quando ele é emprestado ou devolvido.
